# 基于语义的隐式特征变换方法 (SIFT)

## 简介

SIFT是一种小样本学习方法，采用编码-变换-解码流水线，通过语义变换实现从基础类到新类的特征实例直接转移。该方法通过确保语义意义和施加紧凑性约束，为小样本学习任务生成高质量特征。

## 核心特点

- **语义变换**: 使用语义词嵌入来指导特征变换
- **编码-变换-解码流水线**: 三阶段架构进行特征增强
- **紧凑性约束**: 确保生成的特征围绕类中心分布
- **转导/归纳设置**: 支持两种评估范式
- **多种分类器**: 兼容度量学习、基于梯度和非参数分类器

## 快速开始

### 训练
```bash
python run_trainer.py --config config/sift.yaml
```

### 测试
```bash
python run_test.py --config config/sift.yaml
```

## 配置说明

`config/sift.yaml`中的关键配置参数：

- `semantic_dim`: 语义特征维度 (默认: 300)
- `classifier_method`: 分类方法 ('metric', 'gradient', 'nonparam')
- `setting`: 评估设置 ('in' 表示归纳, 'tran' 表示转导)
- `num_aug`: 每个基础类的增强样本数量
- `lr`: 编码器/变换器/解码器的学习率
- `grad_lr`: 基于梯度分类器的学习率
- `ablation`: 消融研究配置

## 实现说明

1. **语义特征**: 当前实现使用随机语义特征作为占位符。为了完整功能，需要集成GloVe词嵌入或其他语义表示。

2. **基础类特征**: 实现从支持样本生成基础类特征。为了最佳性能，应使用来自预训练的实际基础类特征。

3. **线性规划**: 使用PuLP求解原型更新中的分配问题。

4. **内存需求**: 该方法在训练期间需要额外内存来存储生成的特征。

## 消融研究

实现支持多种消融配置：

- `no`: 包含所有组件的完整方法
- `enc_recon`: 不包含编码器重构损失
- `dec_recon`: 不包含解码器重构损失  
- `cpt`: 不包含紧凑性损失
- `all`: 仅包含基本映射损失
